# بيت الكبسة 🍛

موقع مطعم **بيت الكبسة** — عربي بالكامل مع دعم RTL، ويعمل أيضاً **كتطبيق جوال (PWA)** قابل للتثبيت على الشاشة الرئيسية ويشتغل بدون إنترنت.

## المحتويات

| الملف | الوصف |
|---|---|
| `index.html` | الصفحة الرئيسية بكل الأقسام |
| `css/styles.css` | كل الأنماط (نظام ألوان بنّي + ذهبي) |
| **`js/menu-data.js`** | **الأطباق والأسعار وإعدادات الطلب — عدّل هنا فقط** |
| `js/main.js` | التفاعلات: القائمة، البحث، السلة، الحجز، تثبيت التطبيق |
| `manifest.webmanifest` | تعريف تطبيق الجوال |
| `sw.js` | عامل الخدمة — التخزين المحلي والعمل أوفلاين |
| `offline.html` | صفحة تظهر عند انقطاع الاتصال |
| `icons/` | أيقونات التطبيق (SVG + PNG) |
| `amplify.yml` | إعدادات النشر على AWS Amplify |
| `app/` | تطبيق أندرويد أصلي بـ Capacitor — [دليل البناء](app/README.md) |

## نسختا التطبيق

| | PWA | أندرويد أصلي |
|---|---|---|
| **الحالة** | ✅ جاهزة وتعمل الآن | ⚙️ مُجهّزة، تحتاج أدوات بناء |
| **التثبيت** | من المتصفح مباشرة | ملف APK أو Google Play |
| **يحتاج** | لا شيء | JDK 17 + Android Studio |
| **التحديث** | تلقائي مع الموقع | إعادة بناء ورفع |

تفاصيل بناء نسخة أندرويد في [app/README.md](app/README.md).

## الأقسام

الواجهة الرئيسية · المزايا · عن المطعم · قائمة الطعام · الولائم · معرض الصور · آراء الضيوف · نموذج الحجز · الفروع · الفوتر.

## وظائف التطبيق

| الوظيفة | التفاصيل |
|---|---|
| **سلة طلبات** | إضافة أطباق بأحجام وإضافات وملاحظات، تعديل الكميات، حساب الإجمالي |
| **إرسال الطلب** | رسالة واتساب منسّقة تلقائياً بكل تفاصيل الطلب |
| **استلام أو توصيل** | اختيار الفرع، أو إدخال العنوان مع رسوم توصيل وحدّ للتوصيل المجاني |
| **بحث** | بحث فوري في أسماء الأطباق وأوصافها |
| **تصفية** | حسب التصنيف، مع تبويب للمفضّلة |
| **مفضّلة** | تُحفظ في المتصفح وتبقى بعد الإغلاق |
| **حفظ السلة** | لا تضيع عند تحديث الصفحة أو إغلاقها |
| **حجز طاولة** | نموذج بتحقّق عربي يُرسل عبر واتساب |

## تعديل القائمة والأسعار

كل شيء في [js/menu-data.js](js/menu-data.js) — ملف واحد فيه شرح لكل حقل. أضف طبقاً بنسخ أي كتلة موجودة وتغيير قيمها. العرض والبحث والسلة تتحدّث تلقائياً، وحتى عدّاد «طبقاً في القائمة» في الواجهة.

في نهاية الملف `ORDER_CONFIG` — رقم واتساب، رسوم التوصيل، حدّ التوصيل المجاني، أقل مبلغ للطلب، والفروع.

## الاختبارات

٣٩ اختباراً تكاملياً تشغّل الصفحة داخل jsdom وتتحقق من العرض والبحث والتصفية وحسابات السلة والحجز:

```powershell
cd app
npm test
```

## التشغيل محلياً

عامل الخدمة (Service Worker) لا يعمل من `file://`، لذا شغّل خادماً محلياً:

```powershell
# باستخدام Python
python -m http.server 8080

# أو باستخدام Node
npx serve .
```

ثم افتح `http://localhost:8080`.

## تجربة وضع التطبيق

1. افتح الموقع في Chrome على الجوال (أو Chrome على الحاسب).
2. ستظهر لافتة **«ثبّت تطبيق بيت الكبسة»** بعد ثوانٍ، أو من القائمة → *تثبيت التطبيق*.
3. على iPhone: زر المشاركة → **إضافة إلى الشاشة الرئيسية**.

بعد التثبيت يظهر **شريط تنقّل سفلي** بأسلوب التطبيقات، ويعمل الموقع بدون إنترنت.

## ما يجب تخصيصه قبل الإطلاق

- [ ] رقم واتساب الطلبات والحجوزات في [js/menu-data.js](js/menu-data.js) — `ORDER_CONFIG.whatsapp`
- [ ] رسوم التوصيل وأقل مبلغ للطلب في `ORDER_CONFIG`
- [ ] الأسعار وأصناف القائمة في [js/menu-data.js](js/menu-data.js)
- [ ] أرقام الهاتف والبريد في [index.html](index.html)
- [ ] عناوين الفروع وروابط الخرائط
- [ ] الصور الحقيقية: استبدل عناصر `<div class="photo">` بـ `<img src="images/...">`
- [ ] روابط حسابات التواصل الاجتماعي في الفوتر

## النشر على AWS Amplify

الموقع ثابت ولا يحتاج خطوة بناء. الملف `amplify.yml` جاهز — اربط المستودع بـ Amplify وسيُنشر مباشرة.

> عند تعديل أي ملف من ملفات الموقع، **ارفع رقم `CACHE_VERSION` في [sw.js](sw.js)** حتى يستلم المستخدمون النسخة الجديدة بدل المحفوظة.
