# بيت الكبسة 🍛

موقع مطعم **بيت الكبسة** — عربي بالكامل مع دعم RTL، ويعمل أيضاً **كتطبيق جوال (PWA)** قابل للتثبيت على الشاشة الرئيسية ويشتغل بدون إنترنت.

## المحتويات

| الملف | الوصف |
|---|---|
| `index.html` | الصفحة الرئيسية بكل الأقسام |
| `css/styles.css` | كل الأنماط (نظام ألوان بنّي + ذهبي) |
| **`admin.html`** | **لوحة التحكّم — الرابط الخاص لتعديل الأسعار والصور والتواصل** |
| `js/menu-data.js` | القيم الافتراضية للأطباق والأسعار وإعدادات الطلب |
| `js/gallery-data.js` | صور المعرض وإعدادات صور الأطباق |
| `js/main.js` | التفاعلات: القائمة، البحث، السلة، المعرض، الحجز، تثبيت التطبيق |
| `js/admin.js` | منطق لوحة التحكّم (تُحمَّل عند الطلب فقط) |
| `data/site.json` | ما تحفظه اللوحة: الأسعار وأرقام التواصل — يغلب على `menu-data.js` |
| `images/` | صور المطعم — [دليل الأسماء والمقاسات](images/README.md) |
| `manifest.webmanifest` | تعريف تطبيق الجوال |
| `sw.js` | عامل الخدمة — التخزين المحلي والعمل أوفلاين |
| `offline.html` | صفحة تظهر عند انقطاع الاتصال |
| `icons/` | أيقونات التطبيق (SVG + PNG) |
| `amplify.yml` | إعدادات النشر على AWS Amplify |
| `app/` | تطبيق أندرويد أصلي بـ Capacitor — [دليل البناء](app/README.md) |

## نسختا التطبيق

| | PWA | أندرويد أصلي |
|---|---|---|
| **الحالة** | ✅ جاهزة وتعمل الآن | ⚙️ مُجهّزة، تحتاج أدوات بناء |
| **التثبيت** | من المتصفح مباشرة | ملف APK أو Google Play |
| **يحتاج** | لا شيء | JDK 17 + Android Studio |
| **التحديث** | تلقائي مع الموقع | تلقائي في الوضع الحيّ |

تطبيق أندرويد له وضعان:

| | حيّ من الإنترنت ⭐ | مضمّن أوفلاين |
|---|---|---|
| **المحتوى** | يحمّل الموقع المنشور | ملفات مُجمّدة داخل التطبيق |
| **بعد نشر صورة أو تعديل سعر** | يظهر بمجرد إعادة فتح التطبيق | يحتاج إعادة بناء APK |
| **بدون إنترنت** | يعمل من كاش عامل الخدمة بعد أول تشغيل | يعمل دائماً |
| **الضبط** | `npm run live -- https://رابط-الموقع` | `npm run live -- off` |

تفاصيل البناء في [app/README.md](app/README.md).

| الوظيفة | التفاصيل |
|---|---|
| **سلة طلبات** | إضافة أطباق بأحجام وإضافات وملاحظات، تعديل الكميات، حساب الإجمالي |
| **إرسال الطلب** | رسالة واتساب منسّقة تلقائياً بكل تفاصيل الطلب |
| **استلام أو توصيل** | اختيار الفرع، أو إدخال العنوان مع رسوم توصيل وحدّ للتوصيل المجاني |
| **بحث** | بحث فوري في أسماء الأطباق وأوصافها |
| **تصفية** | حسب التصنيف، مع تبويب للمفضّلة |
| **مفضّلة** | تُحفظ في المتصفح وتبقى بعد الإغلاق |
| **حفظ السلة** | لا تضيع عند تحديث الصفحة أو إغلاقها |
| **حجز طاولة** | نموذج بتحقّق عربي يُرسل عبر واتساب |
| **معرض بعرض مكبّر** | ضغطة على أي صورة تفتحها بالحجم الكامل — تنقّل بالأزرار أو الأسهم أو السحب باللمس |
| **صور اختيارية** | كل صورة غير موجودة يحلّ مكانها إطار نائب — فلا تتعطّل الواجهة قبل تجهيز الصور |

## تعديل القائمة والأسعار

**الأسهل:** من [لوحة التحكّم](#لوحة-التحكّم-من-الجوال-) في جوالك — بلا حاسب ولا Git.

**من الكود:** [js/menu-data.js](js/menu-data.js) فيه شرح لكل حقل، وأضف طبقاً بنسخ أي كتلة موجودة. وفي نهايته `ORDER_CONFIG` — واتساب، الهاتف، العملة، العنوان، أوقات العمل، رسوم التوصيل، حدّ التوصيل المجاني، أقل مبلغ للطلب، والفروع. العرض والبحث والسلة وعدّاد «طبقاً في القائمة» تتحدّث تلقائياً.

## لوحة التحكّم من الجوال ⭐

**الرابط الخاص:** `https://<موقعك>/admin.html`

أو من داخل الموقع/التطبيق: **ضغطة مطوّلة (ثانية ونصف) على الشعار**، أو `#admin` في الرابط.

### الاتصال — مرة واحدة لكل جهاز

الصق رمز GitHub من `Settings → Developer settings → Personal access tokens → Fine-grained`، واختر مستودع الموقع وحده وصلاحية `Contents: Read and write`. يُحفظ الرمز على جهازك فقط ولا يُرسل لأي جهة غير GitHub، ويُمحى بزر «محو الرمز».

> الصفحة مستثناة من محركات البحث (`noindex` + `robots.txt`)، لكن أمانها الحقيقي هو الرمز: من لا يملكه لا يستطيع تغيير شيء. لا تُدخل الرمز على جهاز مشترك.

### التبويبات الثلاثة

| التبويب | ما تفعله فيه |
|---|---|
| **الصور** | صورة أي طبق، أو صورة معرض، أو صورة «عن المطعم»، أو **شعار المطعم** (PNG بشفافيته يحلّ مكان الرسمة في الهيدر). الصورة تُصغَّر وتُضغط داخل جوالك قبل الرفع، مع معاينة والحجم قبل/بعد. والإزالة بزر واحد تُعيد الإطار النائب |
| **الأسعار** | تعديل اسم أي طبق وسعره وتصنيفه، إخفاء طبق لا تقدّمه اليوم، حذف طبق، أو إضافة طبق جديد |
| **التواصل** | رقم واتساب الطلبات، رقم الهاتف، العنوان، أوقات العمل، رمز العملة، رسوم التوصيل، حدّ التوصيل المجاني، أقل مبلغ للطلب، والفروع |

كل حفظ = **commit واحد** على المستودع، فيبني Amplify مرة واحدة وتظهر التغييرات للزوار خلال دقيقة إلى ثلاث.

### كيف يعرف الموقع القيم الجديدة

| الملف | يكتبه | يحتوي |
|---|---|---|
| `data/site.json` | تبويب الأسعار والتواصل | الأطباق والأسعار وأرقام التواصل والفروع |
| `images/manifest.json` | تبويب الصور | قائمة الصور المنشورة فعلاً |

الموقع يقرأهما عند كل تحميل ويغلّبهما على القيم في `js/menu-data.js`. وفهرس الصور يمنع طلب أي صورة غير موجودة، فلا طلبات فاشلة ولا مساحات فارغة.

> ⚠️ **بعد أول حفظ من تبويب الأسعار**، يصبح `data/site.json` هو مصدر القائمة — وتعديل `js/menu-data.js` باليد لن يظهر. للرجوع للأصل: احذف `data/site.json` من المستودع.

### أو يدوياً من الحاسب

| ما تريده | ما تفعله |
|---|---|
| صور الأطباق | ضع صورة كل طبق في `images/dishes/` باسم معرّف الطبق (`kabsa-lamb.jpg`)، ثم اجعل `autoDishImages: true` في [js/gallery-data.js](js/gallery-data.js) |
| صور المعرض | ضعها في `images/gallery/` بالأسماء الموجودة في [js/gallery-data.js](js/gallery-data.js)، أو عدّل حقل `img` |
| صورة «عن المطعم» | `images/about.jpg` |
| صورة لطبق باسم مختلف | أضف حقل `img: 'images/dishes/اسمك.jpg'` لذلك الطبق في [js/menu-data.js](js/menu-data.js) |

كل التفاصيل — المقاسات والصيغ — في [images/README.md](images/README.md). والصور كلها اختيارية: ما لم يوجد ملفه يبقى الإطار النائب بالرمز التعبيري ظاهراً.

## الاختبارات

١٥٢ اختباراً تكاملياً تشغّل الصفحة داخل jsdom وتتحقق من العرض والبحث والتصفية وحسابات السلة والحجز والمعرض والعرض المكبّر وفهرس الصور وبيانات لوحة التحكّم ومنطق الرفع إلى GitHub (بلا شبكة حقيقية):

```powershell
cd app
npm test
```

## التشغيل محلياً

عامل الخدمة (Service Worker) لا يعمل من `file://`، لذا شغّل خادماً محلياً:

```powershell
# باستخدام Python
python -m http.server 8080

# أو باستخدام Node
npx serve .
```

ثم افتح `http://localhost:8080`.

## تجربة وضع التطبيق

1. افتح الموقع في Chrome على الجوال (أو Chrome على الحاسب).
2. ستظهر لافتة **«ثبّت تطبيق بيت الكبسة»** بعد ثوانٍ، أو من القائمة → *تثبيت التطبيق*.
3. على iPhone: زر المشاركة → **إضافة إلى الشاشة الرئيسية**.

بعد التثبيت يظهر **شريط تنقّل سفلي** بأسلوب التطبيقات، ويعمل الموقع بدون إنترنت.

## النشر على AWS Amplify

الموقع ثابت ولا يحتاج خطوة بناء. الملف `amplify.yml` جاهز — اربط المستودع بـ Amplify وسيُنشر مباشرة.

> عند تعديل أي ملف من ملفات الموقع، **ارفع رقم `CACHE_VERSION` في [sw.js](sw.js)** حتى يستلم المستخدمون النسخة الجديدة بدل المحفوظة.
